# FEMADOX Python Modern Extensions Pack

Python and FastAPI tools with Ruff, ty, debugging, environments, docstrings and type hints.

## Configuration

For Python/FastAPI development, follow the project's interpreter and Ruff/ty configuration.
The official Python extension has a nested pack that may also install Pylance,
Python Debugger and Python Environments. ty has its own language server; choose
the provider deliberately. This pack does not change your settings.
Django/template tools live in the separate Django Full Extensions Pack.

## Installation and scope

Install through VS Code's Extensions view or Install from VSIX. This pack installs extension references, not their binaries. It does not pin versions, install project dependencies or change editor settings. Nested packs can add their own members. A new machine needs access to the Marketplace.

This is an unofficial community collection, independent of the projects and extension publishers named above.
